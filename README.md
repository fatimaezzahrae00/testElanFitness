I- Présentation du Projet 
    Elan Fitness est une salle de sport 
    Le site actuel est un One pager, c'est a dire que toutes les information sont regroupées dans seule page.
    l'objectif de ce project est de transformer ce site en un site multipage,plus clair,       organisé,Facile a naviguer.
    le projet est réaliser avec HTML et CSS.

II-Obejctif de Projet
    -transformer le site one pager en site multipage 
    -organiser les information dans différentes pages
    crée une page Contact avec un formulaire 
III-Organisation du site
    1 - Accueil 
    *La page accueil présene Elan fitness et donne une premiere impression au visiteur:
             -le logo
            -une présentation du salle 
    2  -A propose 
    *Cette page présente :
            -l'histoire d'Elan Fitenss
            -Les valeur de la salle
            -L'équipe
            -La vision de la salle
     3-Programmes 
     *Cette page présente Les différentes possibillités et de choisir le programme qui convient ou bien aime

     4-Contact 
     *la page contact permet au visiteur de trouver les informations néssaire pour contacter la salle 
            -une formulaire de contact
            -le nom
            -prénom
            -l'adress
            -le message 
            -cordonner de salle

        ACTIVITES REALISEES PENDENT LE PROJET

         1- presontation de méthode agile 
         Une présentation a été réalisée autour de la méthode Agile.

            Cette méthode permet d’organiser le travail en équipe de manière flexible et collaborative.

        La répartition des tâches.
La communication entre les membres.
